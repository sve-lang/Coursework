## 💪 Ключевые сильные стороны и инженерные решения проекта

Этот проект качественно выделяется на фоне стандартных аналитических кейсов благодаря внедрению продвинутых подходов к обработке данных и прикладной бизнес-логике:

1. **Математическое восстановление временных рядов (Time-Series Imputation):** 
   Вместо удаления строк с пропусками в датах промежуточных раундов (`mid_funding_at`, 33.43% пропусков) разработан кастомный алгоритм аппроксимации временных отрезков. На основе расчёта дельты между точками входа и выхода капитала была вычислена математическая середина инвестиционного цикла, что позволило полностью восстановить данные и свести уровень неопределённости к 0.0%.

2. **Динамическое моделирование выбросов по методу Тьюки ($IQR$):** 
   Отказ от сквозного фиксированного порога фильтрации аномалий в пользу категориального анализа. Разработана функция автоматического расчёта индивидуальных межквартильных размахов внутри каждого из 395 бизнес-сегментов отдельно с помощью связки `.groupby().apply()`. Это позволило учесть, что масштабы раундов в MedTech и IT несопоставимы с консалтингом или недвижимостью.

3. **Синхронизация математических порогов с законами бизнеса:** 
   При расчёте нижних границ выбросов по формуле Тьюки алгоритм выдал отрицательное значение ($-\$14.12$ млн). Проявлено продуктовое мышление: показатель был программно скорректирован и ограничен абсолютным нулём в соответствии с законами корпоративных финансов (инвестиции не могут быть отрицательными).

4. **Продвинутая реструктуризация таблиц (Tidy Data):** 
   Продемонстрировано владение сложными трансформациями матриц. С помощью метода `.melt()` широкая сводная таблица была переведена в длинный формат (long-format) для векторизованной передачи данных в многомерные графические конвейеры.

5. **Мульти-масштабный инфографический дизайн и автоматизация:** 
   Разработаны масштабируемые циклы `for` с интеграцией кастомных палитр. Для корректного совмещения на одном полотне несопоставимых величин (от единичных нишевых сегментов до десятков тысяч массовых стартапов) успешно внедрено логарифмическое масштабирование осей (`plt.yscale('log')` / `plt.xscale('log')`).

6. **Программная защита вычислений (Zero Division Protection):** 
   При расчёте коэффициентов годового ROI в знаменатель формулы было интегрировано бесконечно малое смещение-эпсилон (`+ 1e-60`). Это защитило код от падения в системную ошибку `ZeroDivisionError` в разреженных ячейках исторических периодов, где инвестиций в конкретном году не зафиксировано.
